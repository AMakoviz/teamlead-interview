# Установка и настройка окружения jira data center

## Установка Docker
Для развертывания окружения jira, необходим docker CE версии >= 20.10.10 и compose.

Для установки или обновления воспользуйтесь официальной инструкцией, для вашей ОС https://docs.docker.com/engine/install/


## Развертывание jira и postgres

Для развертывания используйте compose файл из репозитория. Для стабильной работы желательно выделить не менее 4ГБ RAM, 2vCPU, 20ГБ дискового пространства. 

Для доступа к jira необходим свободный порт 8080, вы можете поменять его в compose файле при необходимости 

При необходимости "тонкой настройки" контейнера jira, вы можете воспользоваться этим гайдом https://atlassian.github.io/data-center-helm-charts/containers/JIRA/, и внести изменения в compose файл

запустите экземпляр командой (команду выполнять из корня репозитория)

`docker-compose up -d`

Дождитесь инициализации - jira будет доступна по адресу 

`http://<ip адрес ВМ, или localhost>:8080`

Необходимо также провести первичную настройку - ввести имя адмнистратора, и получить ключ по предложенной ссылке

После окончания работ удилате экземпляр (вместе с томами)

`docker-compose down -v`

При необходимости оставить тома (например для переконфигурации), использовать команду

`docker-compose down`
